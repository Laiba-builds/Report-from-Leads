REPORT FROM LEADS / CHROME EDITION / v1.2.5

Paste links. Smart read. Clean report.

Report from Leads pasted job URLs ko read karke ek editable report banata hai: Lead URL · Rate · Vendor name · Job type. LinkedIn ke liye Smart mode normally job tab open kiye baghair public job-detail response read karta hai. Dice, Monster, ZipRecruiter aur company sites zarurat par ek minimized Silent Worker window use karte hain, is liye aapka current tab switch nahi hota.

Existing version se update — reports bachayein

  1. Purani extension mein current batch ko Finish batch karein aur Backup reports download kar lein.
  2. Naya ZIP extract karein. Naye extension folder ke andar ki tamam files usi purane extension folder mein copy/replace karein jo Chrome mein pehle se Load unpacked hai.
  3. chrome://extensions → existing Report from Leads card → Reload. Uninstall na karein aur doosri copy Load unpacked na karein.
  4. Dashboard dobara kholein. Header mein v1.2.5 nazar aana chahiye.

First-time install

  1. ZIP ko Extract all karein aur folder permanent location par rakhein.
  2. chrome://extensions open karein.
  3. Developer mode on → Load unpacked.
  4. Extracted package ka extracted Report-from-Leads folder select karein, jahan manifest.json hai.
  5. Puzzle icon se Report from Leads pin karein aur extension icon click karein.

Silent Background reader kaise kaam karta hai

  • LinkedIn: agar exact job tab pehle se open aur loaded hai, extension usi tab ko bina focus, reload, navigate ya close kiye read kar sakti hai. Warna Smart mode LinkedIn ki public job-detail response ko hidden parser mein read karta hai — normally koi LinkedIn job tab create nahi hota.
  • Other job sites: Smart mode non-LinkedIn job pages ko ek waqt mein sirf 1 dedicated minimized Silent Worker tab mein open karta hai. Har owned job tab kam az kam 20 seconds open rehta hai, phir read complete hone par automatically close hota hai. Ye pages aapke normal Chrome window ke tabs mein nahi khulte, focus nahi lete, aur read hone ke baad automatically close ho jate hain.
  • Low CPU: ek waqt mein 1 silent reader slot. Busy computer / low RAM ke liye.
  • Thorough retry: slow ya incomplete non-LinkedIn leads ke liye longer deadline.

Daily use

  1. URLs paste karein — one individual job URL per line.
  2. Reader mode = Smart Silent rakhein. Foreground/switch-tab option remove kar diya gaya hai, is liye extension hamesha background mein read karti hai.
  3. Read leads & build report click karein.
  4. Report ke fields editable hain aur automatically save hote hain. Manually edited field retry par overwrite nahi hota.
  5. Job type filter se C2C, W2, Contract etc. filter karein; Rate order default high-to-low hai.
  6. Copy table for Excel click karein aur Excel/Google Sheets mein paste karein — Lead URL, Rate, Vendor name aur Job type automatically alag columns aur har lead alag row mein paste hogi.
  7. Remove all leads current report ki sari leads ek click mein clear karta hai, taake next technology ki fresh leads add kar sakein.
  8. Export Excel (.xlsx) se editable 4-column sheet milegi. CSV aur Print/PDF bhi available hain.

Agar LinkedIn lead phir bhi fail ho

  1. Row ka ↗ icon click karke wahi exact LinkedIn job normally open karein.
  2. Job title, company aur description visible hone dein.
  3. Us job tab ko open chhor dein; report par wapas aa kar Retry this lead click karein.
  4. Retry ke dauran us borrowed tab ko doosri job par navigate na karein.

Extension login/CAPTCHA/access checks ko bypass nahi karti. Private, removed, expired ya LinkedIn ki taraf se public detail hide ki hui lead review mein ja sakti hai.

Report logic

Rate: explicit salary/pay range milne par save hota hai; multiple ambiguous pay amounts hon to manual review. Vendor: job page par stated company/vendor. Job type: explicit Contract, C2C, W2, Full-time, Part-time, Temporary ya Internship labels. “No C2C” jaisi negative wording ko C2C eligibility nahi maana jata.

Jo value reliably obtain na ho us field mein Not disclosed aayega. Row ke Reading details ko expand karke reason aur evidence dekh sakte hain.

Your data

Reports aur pending queue isi Chrome profile mein local storage mein save hoti hain. Extension passwords/cookies ko copy ya export nahi karti. LinkedIn Smart public request cookies ke baghair ki jati hai. Job data kisi Report from Leads backend ko upload nahi hota. Website host permission pasted job pages ko read karne ke liye hai.

Silent Worker note: Kuch dynamic job sites ko real browser page chahiye hota hai. Chrome true invisible cross-site tabs provide nahi karta, is liye Report from Leads un pages ko separate minimized worker window mein isolate karta hai. Aapka current working tab/window switch nahi hota. Worker batch ke end, pause ya finish par automatically close hota hai.

Backup reports regularly use karein. Extension uninstall karne se local reports delete ho sakti hain.

Website automation rules apply. LinkedIn ya kisi bhi job board ki login/CAPTCHA restriction ko automatic bypass karna is build ka part nahi hai. Flagged pages ko manually verify karein.
